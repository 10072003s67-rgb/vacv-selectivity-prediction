# VACV: единый внешний датасет для обучения

Основной файл — [`vacv_training.csv`](vacv_training.csv): **2 274 строки по 1 201 молекуле** из открытых измерений ChEMBL. Столбцы повторяют формат Kaggle train (`Title`, `CC50_uM`, `IC50_uM_VACV`, `SI VACV`, `SMILES`, `strain`, `Culture`); дополнительно сохранены `EC50_uM_VACV`, идентификатор источника и качество метки.

| Столбец | Непустых строк | Как использовать |
|---|---:|---|
| `CC50_uM` | 1 674 | Отдельная цель модели цитотоксичности |
| `IC50_uM_VACV` | 236 | Отдельная цель модели активности VACV |
| `EC50_uM_VACV` | 405 | Отдельная цель; не смешивать с IC50 |
| `SI VACV` | 41 | Предварительный CC50/IC50 для совпадающих публикации и клеточной культуры |

В одной строке некоторые метрики пусты: для них нет подходящего точного измерения. Повторяющиеся SMILES означают разные анализы или публикации. `source_id` содержит ChEMBL activity ID; источник доступен через `https://www.ebi.ac.uk/chembl/api/data/activity/<ID>.json` для строк `CHEMBL:<ID>`. Для `DERIVED:<IC50_ID>:<CC50_ID>` указаны оба исходных измерения. Все концентрации приведены из nM в µM; для них взяты только точные значения со знаком `=`. Строки SI помечены `provisional_same_publication_cell_line`: методики ещё требуют ручного сопоставления.

Молекулы, присутствующие в приватных train/test соревнования, исключены по стандартизированному InChIKey. Файлы Kaggle не опубликованы. Для итоговой модели SI используйте локальный train Kaggle как основной источник меток; CC50, IC50 и EC50 из этого файла обучайте как **отдельные задачи**. По правилам соревнования измеренные CC50 и IC50 нельзя использовать как признаки модели, предсказывающей SI по структуре.

Источник данных: [ChEMBL API](https://chembl.gitbook.io/chembl-interface-documentation/web-services/chembl-data-web-services). Обновление: 6 ноября 2026 года.
