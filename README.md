# VACV: внешние данные для прогноза SI

Цель соревнования — предсказать `SI VACV` по структуре молекулы. **`CC50_uM` и `IC50_uM_VACV` запрещены как признаки модели**: по ним можно вычислить целевое значение. В опубликованном [`vacv_training.csv`](vacv_training.csv) этих колонок нет. Таблица содержит **3 896 строк** с хотя бы одной доступной меткой: 41 строку с предварительным `SI VACV`, 427 с `EC50_uM_VACV` и 3 428 с `Potency_uM_VACV`. Кроме меток есть `Title`, `strain`, `Culture`, `SMILES`, `source_id`, `label_quality`.

`EC50` и `Potency` — отдельные показатели, **не метки SI**. Для модели «только по SMILES» входом служит `SMILES`, а целевая колонка берётся только из строк с `SI VACV`. Другие строки могут использоваться лишь в явно отдельной вспомогательной задаче. Из исходных 5 785 записей исключены 1 889 строк, у которых после удаления запрещённых столбцов не осталось ни одной из этих трёх меток.

Метки SI предварительные: пары исходных измерений взяты из одной публикации и клеточной культуры, но методики требуют ручного сопоставления. Они **не заменяют** обучающий файл соревнования. Совпадающие с локальными train/test молекулы ранее исключались по стандартизованному InChIKey. Файлы соревнования в репозитории не публикуются.

## Происхождение данных

В [`reports/added_measurements.csv`](reports/added_measurements.csv) приведены DOI, assay ID и ссылки на 50 дополнительных точных измерений ChEMBL: 29 CC50, 20 IC50 и 1 EC50. Снимок исходных записей находится в [`reports/added_chembl_records.json`](reports/added_chembl_records.json), сводка — в [`reports/expansion.json`](reports/expansion.json). Эти **50 измерений не являются новыми метками SI**. После удаления запрещённых столбцов из новых строк в таблице остаётся только одна строка EC50. Источником идентификаторов послужил [репозиторий Лёни](https://github.com/lenyagrigorenko/lek); сами записи сверены с ChEMBL. Лицензия данных: [CC BY-SA 3.0](DATA_LICENSE.md).

## Воспроизведение

```bash
python -m pip install -r requirements.txt
python scripts/expand_dataset.py --train /path/to/train.csv --test /path/to/test.csv
python scripts/test_expansion.py
```

Скрипт повторно собирает `vacv_training.csv` и отчёт о дополнительных измерениях. Для построения модели используйте только разрешённые входные поля; перед обучением проверяйте список признаков. Доступ к [странице данных Kaggle](https://www.kaggle.com/competitions/molecular-activity-prediction-hack/data) ограничен приглашёнными участниками.
