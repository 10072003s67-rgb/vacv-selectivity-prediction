# VACV: единый внешний датасет для обучения

Основной файл — [`vacv_training.csv`](vacv_training.csv): **5 785 строк** из открытых измерений ChEMBL. Для удобного просмотра метрики стоят рядом: `Title`, `CC50_uM`, `IC50_uM_VACV`, `SI VACV`, `EC50_uM_VACV`, `Potency_uM_VACV`. Затем идут `strain`, `Culture`, `SMILES`, идентификатор источника и качество метки. Названия основных столбцов совпадают с Kaggle train; их порядок изменён для чтения таблицы.

| Столбец | Непустых строк | Как использовать |
|---|---:|---|
| `CC50_uM` | 1 703 | Отдельная цель модели цитотоксичности |
| `IC50_uM_VACV` | 268 | Отдельная цель модели активности VACV |
| `EC50_uM_VACV` | 427 | Отдельная цель; не смешивать с IC50 |
| `Potency_uM_VACV` | 3 428 | Отдельная цель из двух вирусных репортерных скринингов; не приравнивать к IC50/EC50 |
| `SI VACV` | 41 | Предварительный CC50/IC50 для совпадающих публикации и клеточной культуры |

В одной строке некоторые метрики пусты: для них нет подходящего точного измерения. Повторяющиеся SMILES означают разные анализы или публикации. `source_id` содержит ChEMBL activity ID; источник доступен через `https://www.ebi.ac.uk/chembl/api/data/activity/<ID>.json` для строк `CHEMBL:<ID>`. Для `DERIVED:<IC50_ID>:<CC50_ID>` указаны оба исходных измерения. Для CC50, IC50 и EC50 взяты только точные значения со знаком `=`. Концентрации приведены в µM из nM; 18 новых строк с меткой `measured_exact_mass_converted` пересчитаны из µg/mL по молекулярной массе стандартизированной структуры. Строки SI помечены `provisional_same_publication_cell_line`: методики ещё требуют ручного сопоставления.

Строки `Potency_uM_VACV` имеют метку `screen_active_reporter_potency`: это только соединения с отметкой `active` в [Venus](https://www.ebi.ac.uk/chembl/assay_report_card/CHEMBL3215270/) и [mCherry](https://www.ebi.ac.uk/chembl/assay_report_card/CHEMBL3215017/) скринингах. Показатель Potency не является измеренным IC50, EC50, CC50 или SI. Для обучения по нему используйте отдельную задачу; отсутствие строки или пустое значение не означает неактивность.

Молекулы, присутствующие в приватных train/test соревнования, исключены по стандартизированному InChIKey. Строки из `train.csv` и `test.csv` в этот файл не копировались; файлы Kaggle не опубликованы. Для итоговой модели SI используйте локальный train Kaggle как основной источник меток; CC50, IC50 и EC50 из этого файла обучайте как **отдельные задачи**. По правилам соревнования измеренные CC50 и IC50 нельзя использовать как признаки модели, предсказывающей SI по структуре.

Источник данных: [ChEMBL API](https://chembl.gitbook.io/chembl-interface-documentation/web-services/chembl-data-web-services). Обновление: 6 ноября 2026 года.

## Расширение по данным Лёни

Добавлено **50 новых точных измерений**: 29 CC50, 20 IC50 и 1 EC50.
Они охватывают 30 молекул по связности, из которых 7 отсутствовали в прежней базе.
Исходные 5 735 строк сохранены. Новых столбцов в основной CSV нет.
Это расширение вспомогательных задач, **не 50 новых SI-меток** и не доказанное
улучшение метрики Kaggle. Обучение и сравнение моделей в этом обновлении не выполнялись.

Идентификаторы найдены в [репозитории Лёни](https://github.com/lenyagrigorenko/lek),
затем каждое добавленное измерение независимо загружено из ChEMBL.
Чужие усреднённые значения не переносятся: используются отдельные activity ID.
Принимаются точные положительные конечные значения IC50/EC50/CC50 в nM, uM или M,
без отметок недостоверности и потенциального дубля ChEMBL. Повторы по activity ID
исключаются. Добавленные структуры проверены против train и test после удаления
солей и нейтрализации, по связности (также исключаются совпадающие стереоизомеры).
Повторные измерения одной молекулы в разных опытах не считаются новыми молекулами;
при валидации модели разделяйте данные по молекулам/каркасам, не по строкам.

[Происхождение добавленных измерений](reports/added_measurements.csv) содержит
DOI, assay ID и прямую ссылку на каждую запись.
[Отчёт расширения](reports/expansion.json) содержит счётчики и контрольные суммы.
Снимок добавленных исходных записей: `reports/added_chembl_records.json`.

### Воспроизведение

Python 3.9+, команды из корня репозитория:

```bash
python -m pip install -r requirements.txt
python scripts/expand_dataset.py --train /path/to/train.csv --test /path/to/test.csv
python scripts/test_expansion.py
```

Скрипт загружает фиксированные версии исходной таблицы и таблицы Лёни,
запрашивает первичные записи ChEMBL и пересобирает `vacv_training.csv`.
Повторный запуск использует `.cache/expansion`; приватные файлы не публикуются.
ChEMBL может обновляться; для аудита текущего результата сохранён снимок
принятых записей. SI не вычисляется из произвольно подобранных измерений.
